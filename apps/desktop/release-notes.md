Your projects now come first. Studio opens with your recent work above the example games, so you can get straight back to creating.

- A cleaner home and editor, with the full-width top bar removed.
- Consistent light and dark themes across the web and desktop, with a fixed appearance selector.
- A more comfortable mobile layout and previews that stay inside their cards while loading.
- Automatic checks for signed updates. You choose when to install and restart; Studio saves your open work first.

Try Studio in your browser at https://minijs.ambytion.net/studio/, or download the installer for your computer below.

- **Mac:** the `.dmg`. Until Apple code signing is configured, right-click minijs Studio in Applications and choose Open the first time.
- **Windows:** the `.exe` (or `.msi`). If Windows warns, choose More info, then Run anyway.
- **Linux:** the `.AppImage` (any distribution) or the `.deb` (Debian and Ubuntu).

If you installed an earlier copy, install this version once to switch to the public update feed. Future releases appear automatically in the app.

The `.sig` files and `latest.json` support the app's updater. Download the installer, not these files.
