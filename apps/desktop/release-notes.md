Download the installer for your computer below.

- **Mac:** the `.dmg`. Until Apple code signing is configured, right-click minijs Studio in Applications and choose Open the first time.
- **Windows:** the `.exe` (or `.msi`). If Windows warns, choose More info, then Run anyway.
- **Linux:** the `.AppImage` (any distribution) or the `.deb` (Debian and Ubuntu).

Studio checks for signed updates automatically. When the update banner appears, choose Install and restart. Studio saves your open work before installing.

The `.sig` files and `latest.json` support the app's updater. Download the installer, not these files.
