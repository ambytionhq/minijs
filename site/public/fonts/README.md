# Font provenance

Cabinet Grotesk 400, 500, 700, and 800 are self-hosted WOFF2 files from the [Fontshare Cabinet Grotesk family](https://www.fontshare.com/fonts/cabinet-grotesk), supplied through its CSS API.

`phosphor-site-light.woff2` is a 24-glyph subset of `@phosphor-icons/web/src/light/Phosphor-Light.ttf`. It retains the original glyph outlines. The original MIT license is in `Phosphor-LICENSE.txt`; character mappings are in `site/src/icons.css`. Include new glyphs in this subset when adding icons to the landing page.

Geist Sans and Geist Mono remain npm-managed Fontsource dependencies; the site imports their Latin subsets.
